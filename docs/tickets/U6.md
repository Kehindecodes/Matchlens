# U6 · Debug page: signals and z-scores over the match

**Tier** T2 · **Est** 0.5 day · **Depends on** U4 · **Phase** 2 Understanding

## Goal

A page plotting each signal's value and its two z-scores across a whole match, with epoch boundaries marked.

## Read this before building it

This is **T2 and for Kehinde, not for judges.** The backlog is explicit: worth it for calibration work, not for the submission.

But it is also the only way to *see* whether the signals read sensibly, and U3's acceptance criteria can all pass while the signals are still miscalibrated — a signal can be deterministic, correctly windowed, and still fire on nothing a human would notice. If U3's numbers feel wrong, this is how you find out, and it is cheaper than reading them off a terminal for two days.

**So: build it only if U3's calibration is in doubt.** Otherwise it is the first thing in Phase 2 to cut, and cutting it costs the submission nothing.

## What to build

- A plain HTML page with the chart drawn by hand in SVG or canvas. **No chart library** — the stack is pinned and this ticket is not worth a new dependency.
- One row per signal: `value`, `z_match`, `z_prior` on a shared match-clock axis.
- Epoch boundaries as vertical rules, labelled with their trigger, so a baseline reset is visible rather than inferred.
- `confidence` shown somehow — opacity, or a band — because the thin-window cases are the ones worth looking at.
- Reads a finished match from storage. No live streaming; this is an offline tool.

## Acceptance criteria

- [ ] All signals for one match render on a shared clock axis
- [ ] Epoch boundaries visible and labelled with their trigger
- [ ] Baseline resets are visible at those boundaries — if they are not, either the page or U4 is wrong, and this page is how you tell which
- [ ] Low-confidence readings are distinguishable from confident ones at a glance
- [ ] No new dependency added

## Do not

- Do not add a charting library.
- Do not put this on the judge path or in the demo video. It is a workbench.
- Do not build it before U3's numbers exist to look at.
