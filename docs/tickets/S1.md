# S1 · Thirteen module stubs with typed interfaces

**Tier** T1 · **Est** 0.5 day · **Depends on** F1 · **Phase** 1 Walking skeleton

## Goal

Every one of the 13 components exists as a module with its responsibility written down and a typed in/out signature, so the skeleton has somewhere to walk through.

## Why stubs first

The alternative is building stage by stage — finish Ingest, then Understanding, then Signals. That is the horizontal-layer mistake rotated 90°: it ships nothing observable for two weeks, and the first time the stages meet is also the first time they can fail together.

Stubbing all 13 now means S4 can push one hardcoded moment through every stage on day 5.

## What to build

For each component in `docs/ARCHITECTURE.md`:

- A module in the right package.
- The component's **one-sentence responsibility as the module docstring**, copied verbatim from the architecture table. If you find yourself wanting to add an "and", the component is doing two jobs — stop and ask.
- A primary callable with a real type signature, returning the right shape with placeholder content.
- A `NotImplementedError` or a trivially correct return, whichever makes S4 flow.

## The 13 and their signatures

Shapes are the intent; adjust naming to taste, keep the types.

| Component | Rough signature |
|---|---|
| Match Source | `stream(seed, archetype) -> Iterator[Frame \| Event]` |
| Ingest | `accept(item) -> None`, `frame_window(clock_ms, span_ms) -> list[Frame]` |
| Understanding | `observe(item) -> list[SignalReading]` |
| Spotting | `consider(readings) -> Moment \| None` |
| Explanation | `explain(moment, frozen_log) -> list[Claim]` |
| Verification | `verify(claim, record) -> Verification` |
| Personalization | `render(moment, claims, lens) -> Rendition` |
| Catch-up | `summarise(lens, from_clock, to_clock) -> str` |
| Delivery | `enqueue(rendition, session)`, `release_due(session, now) -> list[Rendition]` |
| Session Clock | `viewer_position(session, match_clock_now) -> int` |
| Lens Registry | `get(lens_id) -> Lens`, `all() -> list[Lens]` |
| Control | `mute(lens_id, at_clock)`, `is_muted(lens_id, at_clock) -> bool` |
| Audit | `record(moment, claims, verifications, renditions) -> None` |

## Acceptance criteria

- [ ] All 13 modules exist, import cleanly, and have no import-time side effects
- [ ] Each has its architecture-table sentence as its docstring, with no "and" in it
- [ ] Every primary callable is fully type-annotated
- [ ] A test asserts all 13 are importable and that each primary callable is present and annotated

## Definition of done

Criteria pass, green, status updated.

## Do not

- Do not implement real logic. Stubs only. Each component gets its own ticket.
- Do not wire them together here — S4 does that.
- Do not invent a component that is not on the list of 13. If something seems missing, ask.
