## Goal

A viewer 45 seconds behind the action and a viewer 5 seconds behind each get the same card **at the right point in their own stream.**

## It is a test, not a feature

Nothing ships from this ticket. It is the proof that D1 is real, and it is the clearest possible demonstration of the one thing no competitor does per viewer — so it earns its row by being *demonstrable*, not by adding behaviour.

**Cut ladder rung 4 offers folding it into D1** (*"both tests rather than features, −1, free, take it now"*). That rung has never been taken. With two build days left it probably should be: the assertions below belong in D1's test file either way, and the only thing lost is a separate row in the backlog.

## What to build

- Two sessions on the same lens, offsets of 45s and 5s, one match replay.
- Assert each receives every card, in the same order, at the correct point relative to **its own** viewer position.
- A visible version for the demo if it is cheap: two panels side by side on different offsets, the same goal card landing at different wall-clock moments. That shot explains per-viewer delivery faster than any sentence in the pitch.

## Acceptance criteria

- [x] Both sessions receive the identical set of cards, in the identical order
- [ ] **Identical *content*, not only the identical set** — conditional on A2 enriching against a real model (D36, amended 25 Oct). The same moment must not yield a richer card for the later viewer. Untested while A2 is scripted, because the divergence cannot occur
- [x] The 5s viewer receives each card **earlier in wall time** than the 45s viewer, by the offset difference
- [x] Neither receives a card before their own `match_clock_now − stream_offset_ms` reaches its `display_at_clock`
- [x] Changing one session's offset mid-match does not disturb the other's queue
- [x] An offset of 0 behaves — it is the degenerate case and the one most likely to be special-cased wrongly

## Outcome

- **Identical cards, identical order** — seed 1, viewers at 5 s and 45 s.
- **Earlier by the offset difference** — exactly 40 s of match time for every card; on real time at 40×, within 0.15 s of 1 s (10/10 runs). Wall time is the match-time gap over the replay speed, so at 25× the two panels are 1.6 s apart.
- **Never early** — asserted on every release for both viewers.
- **Changing one offset mid-match** — no endpoint changes an offset after a session is made, so the test replaces the session as `switch_lens` does; the other viewer's releases are identical to an undisturbed run.
- **Offset 0** — each card released on the first tick at or after its clock.
- **Demo** — `/delay`: two panels on the default lens, each with its own score and clock (D32). Live run: the two streams 40 s apart.
- **No delivery behaviour added, no D1 bug found.**
