# F1 · Repo skeleton, module boundaries, config loading

**Tier** T1 · **Est** 0.5 day · **Depends on** — · **Phase** 0 Foundation
**Stories** none directly. This is scaffolding every story rests on.

## Goal

A repo where `pytest` runs green on an empty suite, every component module imports, and configuration comes from one place.

## What to build

- The package layout in `CLAUDE.md` under "Module layout". Create every directory with an `__init__.py`, even the ones that stay empty until Phase 6.
- `pyproject.toml` with the pinned stack. Pin `agent-framework` to an **exact** version — sources disagree on its maturity and a beta SDK with breaking changes mid-build is a real risk.
- `ruff` configured (lint + format). Line length your call.
- `pytest` configured, with `tests/` mirroring the package layout.
- A single config module: `matchlens/config/settings.py`. Pydantic `BaseSettings`, read from environment with sensible defaults for local runs. Nothing anywhere else reads `os.environ`.
- `.gitignore`, `.env.example`.
- A smoke test that imports every component module and asserts nothing raises.

## Config values to define now

- `frame_rate_hz` — **see D13, ask before fixing this value**

- `default_lens_id`
- `match_seed`
- `model_name`, `foundry_endpoint`
- `service_bus_connection`, `database_connection`
- `log_level`
